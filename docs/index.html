The hackable groovebox.

Pushpin turns an Ableton Push 2 and a Raspberry Pi 5 into a standalone instrument: eight tracks of Surge XT and mono2k, a sequencer built for the pads, and no laptop.

Download the image Join the Discord Try the manual

  • Eight tracks in easy to read layouts: each playing Surge XT or mono2k, perfect mix between complex sounds and live tweakability.
  • Performace-focused sequencer: Stage-based design, reimagined by utilizing Push pads for immediate visual feedback
  • Intuitive preset selection: each preset can be seleted and switched independently of sequencer and other tracks.
  • Inter-track audio routing: audio can be routed betwen tracks and Overwitch, enabling complex routing paths — using tracks as sends and busses.
  • Made to be changed: devices and layouts are JSON files, the app is Python.
  • Expanded mono2k voices: Mono2k, LXR-02 and one-sample feedback paths, all in one place.

Guide

Tracks and engines

Pushpin has eight tracks. The lower row of buttons under the display picks one, each lit in its track's colour. Every track plays one engine at a time, Surge XT or mono2k: press Add Track, move with ◀ ▶ and press Add Track again to switch. The choice is remembered.

Devices and controls

A track's sound is split into devices (oscillators, filters, envelopes, effects…). The upper row of buttons shows one device on the display, and the eight encoders above it turn its controls. Press a device's button again, or Page ◀ Page ▶, for its other pages. ◀ ▶ switch between the track's two rows of devices: on a Surge XT track the oscillators, filters, amp and three effects, then six LFOs, the macros and the mod matrix; on a mono2k track the machine, amp, filter, FX, distortion and LFOs, then velocity, key tracking and feedback. Add Device chooses which device fills a slot, such as the oscillator type. Turn the encoders slowly for fine changes and quickly for big ones.

The tempo encoder (top left) sets the tempo, the master encoder (top right) the selected track's volume.

Playing live

Note switches the pads between the keyboard and the sequencer. The keyboard is laid out in fourths, like a bass guitar: the root note is lit in the track's colour and the major scale in white. Octave ▲ Octave ▼ move it, Accent fixes the velocity, and Shift turns the touch strip from pitch bend into a mod wheel.

The sequencer

Each track's sequencer has eight stages, one per column of pads. You edit it a layer at a time, with the buttons right of the pads:

Button Layer The pads set
1/32t Pitch the stage's note in the major scale. Hold two neighbouring pads for the semitone between them.
1/32 Octave the stage's octave.
1/16t Velocity how hard the stage plays.
1/16 Gate the stage's pulses: tap to turn one on or off, Select+pad for the stage's length, Shift+pad for a tie.
1/8t Skip the bottom pad skips the stage; the others set the chance it plays.
1/8 Lock amount how much of the stage's parameter locks it plays.

A good start is the gate layer: give a few stages some pulses, then set their notes on the pitch layer. Play starts and stops every track.

Parameter locks. Hold a pad and turn an encoder: that control takes a different value on that stage only. Stages with locks light white. Hold the pad and press Delete to clear them.

Timing. Scale opens the track's timing page: gate length, how fast and how long this track's sequencer runs, and the main clock's own length. Tracks with different lengths drift against each other, which is the point.

Clips

Session shows every track's clips, one column per track: the clip a track is on in its full colour, its other clips in a darker shade. A clip is the track's whole sequence, every layer and its parameter locks. Tap a pad to switch that track to the clip; the one you leave is saved first, and an empty pad starts a new pattern. Delete deletes the selected track's current clip.

Mutes

Mute shows a column per track and a row per sequencer layer. Tap a pad to mute that layer of that track while it plays: drop the gates and the track goes quiet, drop the pitch and it plays the same note.

Presets

Browse shows eight sound slots per track. Tap a slot to load it. Hold a slot (or hold Select and tap it) to open the browser: the encoders walk the folders, and letting go loads the sound into the slot. A Surge XT slot keeps your edits, written into it when you close Presets, so switching slots before then drops them. A mono2k slot saves itself every few seconds and before you switch away. The upper buttons save a mono2k sound into its slot or as a new preset, and rename user presets, with ◀ ▶ and the arrows to edit the name.

Settings and MIDI

Setup opens Settings and steps through its pages: Performance (root note and aftertouch), MIDI, and About (save, version and software update). To play Pushpin from an external sequencer, set Notes in on the MIDI page to it.

Get started

You need

  • A Raspberry Pi 5
  • An Ableton Push 2
  • An audio interface or an audio HAT, such as the IQaudio DAC
  • An SD card and a way to write images to it
  1. Download the image from pushpin-images.kinga.dev.
  2. Write it to the SD card, for example with Raspberry Pi Imager. Set up Wi-Fi there too if the Pi won't have a keyboard and screen.
  3. Plug everything in and power up. Pushpin starts on its own once the Pi has booted, and plays through the audio HAT (or your interface) even if a screen is plugged in. Switch on the Push 2.
  4. Optional: an external sequencer. Press Setup twice for the MIDI page and pick it under Notes in.

Updating

New images are posted to pushpin-images.kinga.dev. On a running Pi, Setup → About → SW update fetches the latest code and restarts Pushpin.

Troubleshooting

Log in over SSH as pushpin (password pushpin; change it). Pushpin runs as a user service:

systemctl --user status pushpin
systemctl --user restart pushpin
journalctl --user -u pushpin -f

Each synth's own output is in ~/.local/state/pushpin-groovebox/logs/. Ask in the Discord if you get stuck.

Developers

Pushpin is a Python app that grew from Frederic Font's Pysha. It talks to Surge XT over OSC and to mono2k over MIDI, and draws its own screen on the Push 2. The code is on GitHub.

How it starts

The image runs Pushpin as the pushpin user's systemd service. The service runs ~/start_pushpin.sh, which runs ~/s/music_devices/pushpin-groovebox/run.sh and from there app.py. Exactly one copy runs, whether or not anyone is logged in. Stop the service before starting it by hand, or two copies fight over the Push and the OSC ports.

On start, Pushpin launches eight surge-xt-cli processes and the mono2k engine (m2k-jack), waits for them, then starts Overwitch, which runs as its own service (systemctl --user status overwitch).

Audio

PipeWire provides eight duplex devices, pushpin-0 to pushpin-7, with 16 inputs and outputs each, set up in ~/.config/pipewire/pipewire.conf.d/pushpin_groovebox.conf. Pushpin's Audio In device connects them for track inputs, and a further pushpin-volumes device sets the track volumes. Run pw-link -l to see the connections, or ssh -X pushpin@<pi> and run qpwgraph to see them drawn.

Sound goes to PipeWire's default output. A WirePlumber rule (~/.config/wireplumber/wireplumber.conf.d/51-pushpin-prefer-hat.conf) ranks HDMI last, so an audio HAT wins. Check with wpctl status; to change it, wpctl set-default <id> and restart Pushpin.

Devices are JSON

What the encoders control is described in JSON files: Surge's devices in definitions/device_definitions/ and mono2k's in engines/m2k/definitions/. The formats are described by JSON schemas: device, control, message and instrument.
